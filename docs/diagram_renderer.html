Activity Diagram (Roleplay)

activityDiagram
    start
    :User logs in;
    :Select "Roleplay Mode";
    :Choose Avatar & Language;
    
    partition "Roleplay Session" {
        :User speaks into Microphone;
        :System converts Speech-to-Text (STT);
        :Send text to LLM (OpenRouter);
        
        if (Error?) then (Yes)
            :Show Error Message;
            stop
        else (No)
            :LLM Generates Response;
            fork
                :Generate Audio (TTS);
                :Avatar Lip-syncs;
            fork again
                :Show Subtitles;
            end fork
        endif
    }
    
    :User listens/watches content;
    :Update Session Progress;
    
    if (Continue?) then (Yes)
        :Repeat Loop;
    else (No)
        :End Session;
        :Save Chat History;
    endif
    stop

Sequence Diagram (Chat Flow)

sequenceDiagram
    actor User
    participant FE as Frontend (React)
    participant BE as Backend (Express)
    participant OR as OpenRouter (LLM)
    participant DB as Supabase

    User->>FE: Send Message "Hello"
    FE->>BE: POST /api/openrouter {message}
    activate BE
    BE->>OR: POST /chat/completions (Stream=True)
    activate OR
    OR-->>BE: Stream Chunk "Hel..."
    BE-->>FE: SSE Event "Hel..."
    OR-->>BE: Stream Chunk "lo!"
    BE-->>FE: SSE Event "lo!"
    OR-->>BE: Stream [DONE]
    deactivate OR
    BE-->>FE: Close Stream
    deactivate BE

    FE->>DB: Save Message (User)
    FE->>DB: Save Message (Assistant)
    DB-->>FE: Success
    FE-->>User: Update UI (Complete)
